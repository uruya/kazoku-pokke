# 保育園準備に絞った告知文

紹介先: https://kazoku-pokke.jp/about

## SNS投稿用

明日の保育園、何を持っていく？
持ち物や提出物の締切を、ひとりで覚えて家族に伝えていませんか。

「かぞくポッケ」は、保育園の持ち物・提出物・期限を家族で共有できるアプリです。
準備できたらチェック。何が残っているか、家族が同じリストで確認できます。

まずは次の登園日の持ち物を1件から。無料で使えます。
https://kazoku-pokke.jp/about

## 短い投稿用

保育園の「明日の持ち物」「提出物の締切」を、家族で共有。
準備できたらチェックして、毎回伝える手間を少し減らす「かぞくポッケ」を作りました。
まずは持ち物1件から、無料で使えます。
https://kazoku-pokke.jp/about

## 投稿に添える画面・動画

架空のデータで、次の3操作を見せる。

1. 保育園の持ち物に「着替えの補充」と日付を登録する。
2. 招待済みの家族の画面で、同じ項目を確認する。
3. 準備した項目を完了にする。

家族の名前や実際の予定は映さない。募集人数やサポートの約束は、実施できることが決まってから追記する。
